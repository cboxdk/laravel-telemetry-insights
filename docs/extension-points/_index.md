# Extension points

The two capabilities are contracts bound in the service provider, so
replacing one is a binding, not a fork. The API is there for the screen
this package does not ship.

- [Notification channels](channels.md)
- [Your own correlation](correlation.md)
- [HTTP API](http-api.md) — read and change issues and incidents from your
  own screen.
